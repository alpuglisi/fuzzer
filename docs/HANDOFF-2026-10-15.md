## 7. Working rules that matter most (learned the hard way)
- **Lead every status answer with the metric.** If nothing moved, say "nothing moved"
  (F-036).
- **No lab-fitting:**
  - no lab routes, labels or source in code or tests;
  - fixtures come from framework documentation (PA-0154);
  - no per-lab flags in measurements (F-010, F-011, F-049).
- **Measure before design.** Measure real browser and real target behaviour before
  relying on it (CLAUDE.md #8; F-053).
- **Diagnoses cite evidence** (store rows, log lines, a reproduction), never a plausible
  story (F-018, F-055).
- **Verification:**
  - `scripts/verify_change.py --base <ref> --wait-other 3600` before every push;
  - `--full` before every merge;
  - one pytest at a time across all lanes (F-025, F-029).
- **Owner decisions:** policy that limits what the tool sends is the owner's decision.
  Ask; don't impose (F-016, F-050).
- **Lane prompts must say:**
  - which files the lane owns;
  - its pre-assigned numbers;
  - stop and report on a denied action or a mechanism mismatch;
  - no host changes outside its directory (F-057);
  - never read the held-out directories.
- **Failures:** append every new failure to `docs/claude_juicelab_failures.md`, in the
  same turn it is found. The last entry at handoff is F-057.
