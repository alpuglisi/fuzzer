# Reference categories

One folder per input/injection category. Each folder holds the cheat-sheet
documents (`*.md`) at its top level and, where upstream provided them, raw
payload wordlists and payload artifacts under `payloads/`.

- payload-box/xss-payload-list @ 5d88180 — https://github.com/payload-box/xss-payload-list.git
